### Product accuracy rules

- AESG AI is an open-source AI workspace deployed for AESG in AWS. Do not claim that every model call stays inside AWS unless that routing is separately confirmed.
- A project groups chats/tasks, project-visible files and reusable project context.
- Project files are not pasted in full into every prompt. Relevant passages are retrieved for the question.
- Distinguish project-visible files from chat-only files.
- Personal memory follows one user across chats. Project context stays inside the project.
- Do not say Berry "never learns unless explicitly told". The user can enable or disable learning from completed chats.
- A memory import brings across the memories the other assistant exports. It does not recreate full chat history, hidden context or the other provider's exact behaviour.
- Grounded output is evidence-backed, not guaranteed correct. Users still verify technical findings against the source.
